Building a Browser Engine in Rust and WASM

A deep dive into how we built a from-scratch browser engine that runs entirely in WebAssembly.

MR
Max Riabkov
April 7, 2026 -- 12 min read

Introduction

Modern web browsers are among the most complex pieces of software ever built. Chrome alone has over 30 million lines of code. But what if we stripped it all down to the essentials? What does a minimal browser engine look like?

That is the question that led to MiniBrowser, a toy browser engine written in Rust that compiles to WebAssembly and renders HTML/CSS to a canvas element. It is not meant to replace Chrome but rather to explore the fundamental algorithms behind web rendering.

The Rendering Pipeline

Every browser engine follows roughly the same pipeline. Here is ours, simplified:

PIPELINE
HTML String
| html5ever
DOM Tree
| cssparser + cascade
Styled Tree
| layout algorithm
Layout Boxes
| tiny-skia + fontdue
Pixel Buffer

Layout: The Hard Part

Layout is where the real complexity lives. CSS specifies dozens of layout modes, each with intricate rules for sizing and positioning. MiniBrowser supports the three most important ones:

Block layout -- Elements stack vertically, filling their container width.
Flex layout -- Items flow along a main axis with flexible sizing.
Grid layout -- Two-dimensional layout with tracks and cells.

"The web is not just about documents anymore. It is an application platform, and layout algorithms are the foundation of that platform."

-- CSS Working Group, 2023

Painting Pixels

Once layout is complete, we have a tree of boxes with absolute positions and dimensions. The paint phase walks this tree and draws each box onto a pixel buffer using tiny-skia, a pure-Rust 2D rendering library.

rust
fn paint_box(pixmap: &mut Pixmap, lb: &LayoutBox) {
paint_background(pixmap, lb);
paint_borders(pixmap, lb);
paint_text(pixmap, lb);
for child in &lb.children {
paint_box(pixmap, child);
}
}

What is Next

MiniBrowser is a work in progress. On the roadmap: inline layout improvements, CSS transforms, image loading from URLs, and better text shaping. The goal is not completeness but rather a clear, educational implementation of browser fundamentals.

If you are interested in browser internals, clone the repo and start experimenting. The entire engine is under 3,000 lines of Rust.
